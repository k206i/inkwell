## 📜 Лор

Где-то в будущем хранится архив русской литературы. Время не пощадило рукописи: буквы выцвели, пробелы стёрлись, страницы покрылись пятнами. Архивариус Саэлиан восстанавливает их одну за другой, и ей нужен помощник, который знает, как пишется каждое слово.

Древнерусские книги писали сплошным письмом, без пробелов между словами. Так что расставлять пробелы в старом тексте — давняя работа исследователей рукописей.

Саэ не говорит словами. Её настроение видно по визору: улыбка, удивление, грусть или вопрос.

## ✒️ Возможности

- **Восстановление текста.** Абзацы из классики с пропущенными буквами и пробелами, в которые нужно вставить недостающие символы.
- **Викторины.** Выбор правильного написания слова.
- **Диктанты.** Саэ зачитывает фрагмент из звукового архива, его нужно записать.
- **Чернила и кляксы.** Каждая буква тратит чернила, исправление стоит дороже. Ошибки копятся каплей на пере, и третья срывается кляксой.
- **Чистовики.** Страница без клякс становится чистовиком и уходит в архив.
- **Инструменты архивариуса.** Перья и чернила за восстановленные страницы. Меняют только вид, на сложность не влияют.
- **Режим без давления.** Без чернил и клякс, просто практика.
