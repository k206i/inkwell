# Публикация «Чернильницы» в RuStore

## Какой APK грузить

- `inkwell-vX.Y.Z.apk` из артефакта `store-apk` прогона «Release APK» в GitHub Actions (собирается по пушу тега `v*`). Тот же файл прикреплён к GitHub-релизу: сборка одна, проверки обновлений с GitHub в приложении нет.
- Если проверка обновлений появится, сборок станет две, как в «Дне рождения»: в магазин уходит только сборка без неё.
- versionCode считается из тега: MAJOR*10000 + MINOR*100 + PATCH (1.2.3 → 10203) и должен быть больше, чем у версии в магазине.

## Проверка APK перед отправкой (Git Bash, Windows)

```bash
BT="$LOCALAPPDATA/Android/Sdk/build-tools/37.0.0"
```

- `"$BT/aapt2.exe" dump badging APK`: пакет `ru.kliukin.inkwell`, версия, targetSdk 36. Разрешения только INTERNET, VIBRATE и служебное AndroidX `DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`. Любое новое разрешение требует пояснений для модератора и правки `PRIVACY.md`.
- `"$BT/aapt2.exe" dump xmltree --file AndroidManifest.xml APK`: нет debuggable, testOnly, usesCleartextTraffic.
- `"/c/Program Files/Android/Android Studio/jbr/bin/java.exe" -jar "$BT/lib/apksigner.jar" verify --print-certs APK`: схема v2, сертификат CN=Pavel Kliukin, SHA-256 `70deedfb9534d515373809319e82661bca001a85ecfb11443b23b4020adb50f7` (тот же ключ, что у «Дня рождения»).
- `"$BT/zipalign.exe" -c -P 16 4 APK`: выравнивание в порядке.
- Распаковать и поискать в `assets/public`: нет тестовых данных и моков, в `assets/capacitor.config.json` нет `server.url`, есть последние правки из кода. Тег релиза должен стоять на нужном коммите.

## Иконка и заставка

Исходник один: `resources/icon.png` 1024×1024, как в «Дне рождения». Иконка для карточки RuStore лежит отдельно: `design/rustore_icon.png`, 512×512.

```bash
npx capacitor-assets generate --android --iconBackgroundColor '#191421' --splashBackgroundColor '#191421' --splashBackgroundColorDark '#191421'
```

- Цвет фона берётся с фона самой картинки, иначе на стыке слоёв иконки будет шов. Прозрачный фон не использовать.
- Только простой режим с одним `icon.png`. В полном режиме (`icon-foreground`, `icon-background`, `icon-only`) инструмент пишет один `ic_launcher.xml` из десятка потоков сразу и на Windows почти всегда падает.
- В простом режиме гонка тоже иногда случается: `EBUSY` на `ic_launcher.xml`. Помогает запустить команду ещё раз. После успешного запуска все иконки и заставки должны обновиться, а не часть.
- Инструмент каждый раз переформатирует `AndroidManifest.xml`, по смыслу ничего не меняя. Вернуть его: `git checkout -- android/app/src/main/AndroidManifest.xml`.

## Поля формы RuStore

- **Что нового**: абзац с эмодзи о главной новости, ниже мелочи пунктами «•». Писать относительно версии, которая сейчас в магазине (уточнить у пользователя, изменения смотреть через `git log vСТАРАЯ..HEAD`). Версию в тексте не указывать. Пасхалки не раскрывать.
- **Комментарий для модератора**: до 180 символов, сухо и технически. Что поменялось, и отдельно: «Нативная часть, плагины и разрешения не менялись», если это так.
- **Чувствительные разрешения**: до 1500 символов, но коротко и по сути. Сейчас чувствительных разрешений нет.
- **Краткое описание**: до 80 символов.
- **Полное описание**: до 4000 символов, разделы с пунктами «•». Без дешёвого бахвальства цифрами.
- **Название в карточке**: можно «Чернильница: диктанты и правописание», чтобы не путали с блокнотом «Чернильница» в «Полезных инструментах».
- **Политика конфиденциальности**: `https://github.com/k206i/inkwell/blob/master/PRIVACY.md`. Обновлять вместе с функциями, которые трогают данные пользователя.

## Стиль текстов

- Никаких интонационных тире: только там, где тире нужно грамматически. Иначе запятая, двоеточие или точка.
- «Достижения», а не «ачивки». «Серия», а не «стрик».

## Порядок работы

- Ничего не править в файлах без явного «да» пользователя. Сначала план или черновик текста, потом ждать.
- Сборку с новым чувствительным разрешением не отправлять, пока не готовы политика и пояснения для модератора.
